How to read the wireframes

Each wireframe is a picture followed by a numbered list. The list is the full text equivalent: reading and focus order, landmarks, heading levels, controls and their tier. Numbers in the picture match the list. The pictures are hidden from screen readers so the content is not read twice.

  • Book Primary action. One per view.
  • Menus Secondary action.
  • Call Text action.
  • Object One of the six approved objects (moment).
  • Row · £11 Ledger: facts set as rows.
  • H2 Real heading level.
  • 3 Order marker, matches the list.

2. Navigation model

The same items in the same order on every page. Context (the branch whose pages these are) changes where Book, Call and Menus go, never which items exist.

3. Journeys

Critical tasks, with the paths that go wrong. Dashed steps happen off our site. Tap counts are counted on our pages only.

J1 · Book a table tonight

Tonight decider, phoneGoogle → /soho/Our taps: 2 (as today), now confirmed

  1. Lands on Soho. First screen: "Open until 10.30pm", Book a table, See the menus; the facts row below it.
  2. Taps Book a table. The drawer opens for Soho: today, 2 guests, first time after 7pm chosen.
    • Closed today: opens on the next open day and says "Soho is closed on Sundays".
    • Last booking passed: tomorrow, said in words.
    • No JavaScript: the link goes to /book/?branch=soho.
  3. Changes guests, day or time if needed.
    • 8 or more guests: the group path (set menu) (J3).
  4. Taps Find a table. OpenTable opens in a new tab with the choices.
    • Pop-up blocked: same tab.
  5. The drawer stays open: "OpenTable is open in a new tab: 2 guests, Saturday 21 November, 7pm. Not there? Open OpenTable again." Close returns focus to Book.
  6. Books on OpenTable.Provider

J2 · Check the menu for a diet, then book

Dietary guest, phoneFrom /covent-garden/Our taps: about 6 and a 38–44 screen page → 4–5

  1. Taps Menus in the dock. /covent-garden/menu/ opens on À la carte, under "Covent Garden › Menus".
  2. Taps Show only: VG. "14 dishes" is announced; a line offers "There's also a full Vegan menu".
    • Nothing matches: "No dishes match … " with Clear filters and Search all menus.
  3. Or opens "Menu: À la carte ▾" and picks Vegan. The address becomes #vegan; Back returns to À la carte.
  4. Reads the allergy note; Allergens and dietary needs is one link away.
  5. Taps Book (dock or page foot). The drawer opens for Covent Garden; it never asks "Where?".
  6. Find a table → SevenRooms.Provider

J3 · Plan a group of 12

Group organiser, desktopAny pageOur taps: about 17 → about 6; room, date and guests not retyped

  1. Header Groups → /private-dining/, or Book a table → the drawer.
  2. In the drawer, types 12 into the guest number.
    • Above the room's online limit (Soho: 8 or more is a set-menu group, from the data): Find a table is replaced by "Send a group enquiry", with Call beside it.
  3. Picks a day, taps Send a group enquiry. The groups page opens with room, date and guests filled in.
  4. Adds name, email and the occasion; taps Send enquiry. The button shows it is busy.
    • A field missing or wrong: a summary at the top, focus on the first field, each message says what to do.
    • Network fails: nothing is lost; "Try again, or email reservations@fattpundit.co.uk".
  5. "Enquiry sent" replaces the form: what was sent and when to expect a reply (client to confirm).
  6. Receipt by email; the restaurant replies.Email

J4 · Find the door

Guest on the street, phone/covent-garden/Our taps: 1

  1. Facts row: 6 Maiden Lane, WC2E 7NA; nearest stations Covent Garden, Charing Cross.
  2. Taps Directions (new tab announced).
  3. Google Maps walks them there.Maps app
    • Running late: Call 020 7836 8883, in the same row and the dock.

J5 · Join the Dubai list

Dubai local, phoneInstagram → /dubai/Our taps: 3 → 2, and the email is kept

  1. First screen: Opening soon at The Hangout, Mall of the Emirates; Join the list.
  2. Join the list moves focus into the email field; the keyboard opens.
  3. Types an email, taps Join the list. The button shows it is busy.
    • Not an email: "Enter an email address like name@example.com".
    • Network fails: "We couldn't add you. Try again in a moment." The email stays in the field.
  4. "You're on the list. We'll email you when Dubai takes bookings." Focus moves to the message.

First visit, desktopInstagram → /Unchanged: the story is the brand's main asset
