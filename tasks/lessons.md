# Lessons

Review at the start of every session. Add a line after any correction.

- Astro here is v7: content config lives at `src/content.config.ts`, collections use `file()` loaders, Zod comes from `astro/zod` (Zod 4: `z.email()`, `z.url()`).
- Fonts use Astro's built-in `fonts` config with `fontProviders.local()`; load them per page with `<Font cssVariable=... />` from `astro:assets`.
- Menu data source of truth = live site (18 Nov 2026), not the guidelines PDF. Differences live in docs/content-discrepancies.md until the client confirms.
- Covent Garden books through SevenRooms, Soho through OpenTable (old site embeds). Don't trust the old home page's ResDiary link.
- Never select by a data-attribute that is also set on <html> (data-arrival): querySelector('[data-arrival]') returned <html> and .remove() wiped the page. Use a unique overlay attribute.
- CSS custom properties holding url() resolve against the stylesheet, not the page: put mask-image URLs directly in the inline style.
- Demo export: Vite's preload helper prefixes "/"; scripts/export-demo.mjs rewrites it to page-relative. Host reserves "_" prefixes, so assets ship in assets/.
- Layout checks that sample while scrolling inside one synchronous evaluate never let IntersectionObserver callbacks run: UI driven by them (the Phase 8 dock) is measured in its initial state. Measure page-body bands inside main only.
- `.branch :global(p) { margin: 0 }` also beats single-class margin-top on a <p> (Dubai's Book in London sat flush): use padding, or a div.
- SplitFlapText: a full-drum spin reads as noise; cap trips with maxFlips and fire follow-ups from onSettled, not timers.
- anime.js draw: set strokeDasharray as an SVG attribute, never inline style (inline style wins and the draw never shows).
- Calm mode must show the END state of a scrubbed scene, including moving parts (ship parked at London), not the start.
- A crossfade between two maps only reads as one camera move if transform-origin + scale are solved from shared city points.
- Headless screenshots of a WebGL canvas that is partly off screen can come back black or transparent. Check the real pixels with gl.readPixels before "fixing" the shader.
- Paginating content into fixed pages: measure real block heights in a hidden copy (cqw units scale with width), don't guess from character counts.
- Layers that must move together (a paper sheet and its wash) go in ONE element; a separate unrotated overlay leaves a wedge.
- Multi-page static demo on a sub-path: give sub-pages <base href="../"> and rewrite internal links to explicit index.html paths; hash-only links on sub-pages must point at their own page or <base> sends them home.
- import.meta.glob with eager:true emits every matched file: glob only the folders the page needs.
- Sticky scenes under a sticky site header need top/height offset by the header, or their headings hide under it.
- Astro scoped styles don't reach elements rendered inside a child component (a <video> from LoopVideo): style them with :global() from the page.
- Check AI motion clips by numbers, not just eyes: diff each frame against the source photo (mean diff + % pixels changed), then look.
- Scroll triggers ("at mid-screen") must fire where people actually stop: test at phone size; trigger when the element's middle passes ~65% down, not dead centre.
- Light added on a bright photo is invisible: darken the scene first (multiply grade), then add the glow (screen blend) — contrast sells it.
- A camera over a big detailed map: one pre-drawn image moved by transform only (will-change), plus a light SVG overlay whose viewBox follows the same camera. Draw the chart wider than the route so the camera never sees its edge.
- Thin line art (the gold junk) disappears on a busy background: put it on a solid badge.
- Test touch gestures with the target fully on screen and clear of the sticky header, or the test swipes the header.
- window.open(url, '_blank', 'noopener') ALWAYS returns null, so it can't detect a blocked pop-up. Open without the feature, then set w.opener = null; fall back to same-tab only when w is null.

- User feedback 18 Nov (phone): blur, foggy glows, unreadable logo, text spilling out of plates, page opening at the bottom. Root lesson: review every scene on a real phone-size screenshot before publishing, and never put text or the logo on a busy photo, stretch a 1024px photo full-screen, or let decorative light cover a photo.
- The Claude app viewer can keep the previous page's scroll on navigation: pages must reset to top themselves (keep back-button restore).
- AI upscalers invent fine lettering (faint Chinese characters became fake glyphs). Always check text areas side by side at 1:1 before using an upscale; a whole-image drift number won't catch it.
- Small round labels (plates ~55px on phones) can't hold names: show the short fact (price) on the shape and the full name in a caption line nearby. Size names from the longest word with container units.
- CSS @container units measure the content box (inside padding/border) — set thresholds and formulas against that, not the outer shape.
- An overflow checker must skip deliberately hidden things (skip links, off-screen tracks, clipped book pages) and treat zero-size boxes carefully, or the noise hides the real issues.

- Links inside a React island break in the sub-path demo (the exporter only rewrites static HTML). Put link-heavy UI in an Astro component and slot it into the island; use document-level click delegation, since the island can re-mount slotted HTML (listeners on the old nodes are lost).
- Astro's <astro-slot> wrapper is display:block inside islands: it shrinks to content in a flex parent. Size it from the parent ([&>*]:w-full).

- Scroll stutter in headless came from raster, not JS: an SVG <img> under a zooming camera re-rasterises per zoom (1.4 s raster). Ship detailed vector art as a picture when it's scaled by transform; cap layer size in device px.
- Animate opacity of a dark layer, never `filter: brightness`, inside scroll scenes. Write transform/opacity straight onto elements instead of custom properties on a parent (whole-subtree style recalc per frame).
- An intro that starts at opacity 0 makes it the LCP element and drags LCP to the end of the intro. Paint it finished; animate a press, not an appearance.
- Lighthouse simulated LCP counts high-priority JS before paint: `client:load` islands in the hero cost ~1 s of lab LCP; `client:idle` fixed it. Check `observedLargestContentfulPaint` before chasing lab LCP.
- Inlining all CSS (88 KB) made FCP slower than three cached files. Measure before keeping a "best practice".
- Distressed one-colour stamps: palette PNG (sharp png quality<100) is 3× smaller than WebP/AVIF; the noise is what costs bytes.
- To find what janks: record scrollY of slow frames, then trace — `RasterTask` vs `FunctionCall` tells raster from script.
- Visually hidden inputs (`position:absolute; opacity:0`) inside a horizontal scroller escape it unless their label is `position:relative` — they widened the whole page to 566px.
- A `<fieldset>` defaults to `min-width: min-content`; give it `min-width:0` inside flex/grid or its nowrap children push the page wide.
- JS-filled text that changes line count after first paint (live status, clocks) is a layout shift: reserve the width and `nowrap` it. Preloading the font a hero line uses fixed the rest (CLS 0.17 → 0.001).
- Lab LCP for text adds preloaded fonts; judge real paint by `observedLargestContentfulPaint` and keep CLS fixes.
- Scoped Astro CSS doesn't reach elements made in JS; use `.parent :global(.child)`.
- Detached `requestIdleCallback` throws "Illegal invocation"; call it on `window`.
- Python str.replace with an empty 'old' inserts at every character: always assert the slice/old text is non-empty and found exactly once before replacing (a bad index() blew a page up to 695k lines).
- A focus ring in a brand accent fails 3:1 on the brand's own paper: colour the ring by the surface (custom property set on surfaces, never on the control itself, since the ring sits outside the control).
- "Empty" screens in a headless sweep can be capture timing (letter-by-letter titles, receipts printing): re-check one screen with a longer wait before redesigning it.
- Removing `white-space: nowrap` from a line next to a late-loading font brings layout shift back (CLS 0 → 0.215): keep single-line slots single-line, change the layout instead.
- Split-flap boards that step alphabetically can spell words mid-flight: animate through digits/signs, never letters.
- Compare perf against the previous build in interleaved runs on the same machine before calling something a regression (a git worktree on another port does it).
- `npm i` prunes hand-made symlinks in node_modules (playwright): re-link before perf:budget, or the budget silently can't run.
- Windows PowerShell 5.1 `Get-Content -Raw` reads BOM-less UTF-8 as ANSI: a read/replace/write round trip mangles → × “ ’. Edit files with the Edit tool or Python (utf-8), never a PowerShell string round trip.
- `outline-color` reads as currentColor whenever `:focus-visible` didn't match, so a ring check can silently pass. Check the `--fp-ring` token on the control instead.
- A script that switches a page into its JS layout (one-menu mode) must run BEFORE the markup it changes is parsed; placed after it, a slow connection paints the no-JS layout first (CLS 0.18). Draw JS-only controls from a class set early, not by un-hiding them in a module script.
- Test the budget on every page you touch, not only the default PAGES list: the menu page's 0.18 CLS had never been measured.
- A temporary worktree with a node_modules junction: unlink the junction with `cmd /c rmdir <junction>` (removes the link only) before deleting the folder, and check the real node_modules count after. PowerShell Remove-Item on it prompts and fails in non-interactive mode.
- A test that changes page state (a filter) and then navigates by hash on the same document keeps that state: load about:blank first, or the "failure" is the test.
- Global `h2` styles uppercase: any new heading class must set `text-transform: none` itself.
- A vertically centred hero shifts on slow loads: the browser can paint before the HTML has all arrived, and the centred column slides up as the rest streams in. Top-align (or stretch) a column that grows, and decide it from a server-rendered class, never `:has()` on content still arriving.
- A chapter head and its content must share one section and one surface; a head on its own band reads as an orphan strip. Count the colour changes per screen before calling a page done.
- `.branch :global(p) { margin: 0 }` (0,1,1) beats a single class on a `<p>`: use padding for offsets on paragraphs inside the branch page.
- An italic Lora line above content re-wraps when Lora lands (its Georgia fallback is wider), and everything below it jumps. Short UI lines above the fold go in the body face, whose fallback is width-matched.
- A hydration that Lighthouse charges at load (client:idle) can be moved to `client:visible` with a rootMargin of a screen: TBT 490 → 110 ms on home. Measure the scroll test before and after; it can move the cost into the scroll.
- "Empty band" and "surface change" checks must count only edge-to-edge backgrounds and split gaps at a change of surface, or cards, fields and two chapters' padding read as failures.
- Re-validating a field on blur moves the form (its message disappears) just as the guest taps the next control, and the tap misses. Clear errors on input.
- Base.astro re-asserts scrollTo(0,0) until 300 ms after `load` on a fresh visit: a test that scrolls straight after `goto` is scrolled back and screenshots the top. Wait ~450 ms (or dispatch a wheel event) before scrolling.
- In Git Bash, `OUT="$(pwd)/screens"` passed to Node with MSYS_NO_PATHCONV=1 is a POSIX path (`/c/Users/...`) that Node resolves to `C:\c\Users\...`. Give Node scripts Windows-style paths.
- Playwright `page.check()` on the 1 px hidden input behind `.fp-choice` times out: click the label. A sticky bar or the dock over a target also times out a click: scroll it to `block: 'center'` first.
- Two sessions (claude.ai and Claude Code) worked on the same repo and main was replaced with new history. Fetch and compare with origin/main before starting work, and port onto the newest main in a branch; never force-push.
- Astro's scoped `<style>` pipeline drops `animation` + `animation-timeline` declarations nested in `@supports`/`@media` (the built rule is empty). Put scroll-timeline rules in global.css, as longhands, and read the rule back from `document.styleSheets` after a build.
- `height: auto` does not interpolate (even with `interpolate-size`) for a flex item in a column: use `grid-template-rows: 0fr → 1fr` with an inner wrapper. Keep `interpolate-size` transitions behind `@supports (interpolate-size: allow-keywords)` or `allow-discrete` flips them 130 ms late elsewhere.
- Dialog exit transitions need `overlay` (Chromium only); keep the keyframe entry and put `transition-property: …, overlay, display` behind `@supports (overlay: auto)`. Transitions beat `!important` (`[hidden]`), so a `display` transition still holds the box open.
- "Scroll jank" in a pinned scene was its wake-up, not its frame loop: 1,443 `getPointAtLength` calls in the hydration effect = 750 ms at 4× CPU, one frame of the first scroll. Before rebuilding a per-frame path, hide the scene (`display:none` variant) and time the wake-up with a `longtask` observer; slice geometry work with `requestIdleCallback`. Swapping a per-frame `viewBox` for a transformed `<g>` changed nothing measurable (raster, not layout, was the per-frame cost).
- `if ('requestIdleCallback' in window) … else window.setTimeout(…)` fails astro check: lib.dom declares the API, so the else branch narrows `window` to `never`. Feature-test with `typeof window.requestIdleCallback === 'function'`.
- A tap's cost hides in its handler, not its animation: opening the Book drawer drew 21 day chips + times on the click (250 ms at 4× CPU). Measure input-to-paint with the Event Timing API on real clicks (`scripts/tap-timing.mjs`); pre-draw at idle.
- A nav button disabled at the edge (`spread === 0`) cannot reverse a turn in flight: keep the opposite control live while something is heading somewhere. The interruption test caught it on page 1 at phone width only.
- Tailwind 4 preflight ships `[hidden]:where(:not([hidden=until-found])){display:none!important}`: a component's `display:grid` does NOT un-hide `[hidden]` here. Grep the built CSS (dist/_astro), not only src/styles, before calling a hidden-box bug — and prove it in a browser (audit 24 Nov: the "booking contradiction" was a scraper reading hidden nodes' text).
- Opening-anchored half-hour slots give a room that opens at 16:45 a :15/:45 grid; any UI that shares one time list across rooms (the /book/ desk) then finds no common time. Compare slot grids across branches when touching booking.
- User correction 24 Nov (audit directions): the client wants the CURRENT immersive journey (arrival, rain glass, doors, curtain, voyage, menu book, bar, room, boarding passes) kept and made richer with motion, not cut down to a "less is more" page. Premium here = the same journey, more polished and more alive; fix overload inside scenes (copy, controls, footer), never by removing scenes. Don't propose removing a scene without asking.
